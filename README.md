# MolcaForge — downloads

Installers and the landing page for **MolcaForge**, Molca's desktop app for Windows and macOS:
**MolcaRepo** (Git version control, beginner-friendly) and **MolcaVault** (the office NAS, preview).

- **Download:** see the [latest release](https://github.com/molca-id/molca-forge-releases/releases).
- **How to use it:** read the [User Guide](USER_GUIDE.md).
- **Something misbehaves?** [Open an issue](https://github.com/molca-id/molca-forge-releases/issues).

| System | File |
| --- | --- |
| Windows 10/11 | `MolcaForge-Setup-<version>.exe` |
| macOS, Apple Silicon (M1–M4) | `MolcaForge-<version>-mac-arm64.dmg` |
| macOS, Intel | `MolcaForge-<version>-mac-x64.dmg` |

MolcaForge needs **Git ≥ 2.28**, and you sign in with your **OHARA** account.

This repository holds only the installers, the landing page (`index.html`) and the User Guide. The source code lives elsewhere.
