Mulai

Pasang MolcaForge di komputermu

Dua langkah. Unduh installer sesuai sistemmu, lalu pasang dan masuk dengan akun Molca.

  1. Unduh installer

    Pilih file sesuai sistem operasimu.

    MolcaForge butuh Git ≥ 2.28 di komputermu. Ambil dari git-scm.com kalau belum ada.

  2. Pasang dan masuk

    Jalankan installer, buka MolcaForge, lalu masuk dengan akun OHARA lewat browser.

    Windows

    Installer belum code-signed, jadi SmartScreen mungkin memberi peringatan. Klik More info → Run anyway.

    macOS

    Seret MolcaForge ke Applications. Aplikasi belum dinotarisasi: pertama kali, klik kanan → Open → Open, atau jalankan ini sekali di Terminal.

Tidak perlu akun GitHub. Installer bisa diunduh siapa saja. Untuk memakai aplikasinya kamu masuk dengan akun OHARA, jadi hanya orang Molca yang bisa masuk.

Versi ini masih pre-release dan sedang diuji. Versi lama, catatan rilis, dan plugin Unity ada di halaman rilis.

Modul

Satu aplikasi. Dua modul.

Masuk sekali, lalu pilih modul dari menu utama.

01

MolcaRepo

Version control Git.

Repository, perubahan, riwayat, branch, dan Pull Request. Hubungkan akun GitHub, GitLab, Bitbucket, dan Gitea, bisa banyak sekaligus, dengan Git LFS, kunci file, serta alat untuk Unity dan artist.

02

MolcaVaultPreview

NAS kantor.

Jelajahi, pratinjau, unggah, dan bagikan file tim. Drag and drop untuk memindahkan dengan undo, dan plugin Unity untuk unggah dan unduh langsung dari Editor. Masih preview: untuk sekarang memakai data contoh.

Fitur

Mudah dimulai. Lengkap saat dibutuhkan.

Semua yang bisa dilakukan GitHub Desktop, ditambah yang benar-benar dibutuhkan tim game dan art.

01

Mode pemula & Asisten

Tips di setiap tombol penting, saran langkah berikutnya, dan error Git dijelaskan dengan bahasa sehari-hari plus perbaikan satu klik.

02

Time Machine & Undo pull

Kembali ke titik mana pun dengan aman. Perubahan yang dibuang selalu dicadangkan ke Stash, dan pull yang berantakan dibatalkan satu klik.

03

Satu daftar perubahan

Centang file untuk di-commit, pilih banyak sekaligus, atau per hunk dan per baris. Graf commit lengkap, rebase, dan cherry-pick.

04

Unity: .meta & GUID

Mendeteksi GUID yang berubah serta .meta yatim dan noise, memulihkan GUID lama, dan menyiapkan .gitattributes serta .gitignore satu klik.

05

Untuk artist

Konflik visual dengan thumbnail, perbandingan gambar sebelum dan sesudah, versi sebelumnya per file, dan pemulihan file terhapus.

06

Git LFS & kunci file

Wizard aktivasi untuk file besar. Kunci file art sebelum diedit supaya dua orang tidak saling menimpa pekerjaan.

07

Banyak akun

Akun kantor dan pribadi berdampingan. Tiap repository memilih akun yang tepat secara otomatis, dan login lewat browser tanpa token.

08

Command Palette & terminal

Semua aksi dari Ctrl+K (⌘K di macOS), log setiap perintah git yang dijalankan tombol, dan terminal Git bawaan.
